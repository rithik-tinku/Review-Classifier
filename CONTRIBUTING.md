# Contributing

Thanks for helping improve Review Classifier.

## Before you open a PR

- Run the test suite.
- Keep changes focused and avoid unrelated refactors.
- Update docs when behavior changes.
- Do not commit secrets, model checkpoints, or generated artifacts.

## Suggested workflow

1. Create a branch.
2. Make the smallest useful change.
3. Run tests and basic app checks.
4. Submit a concise PR summary with verification notes.
