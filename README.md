# Review-Classifier
This project analyzes customer reviews and converts them into meaningful business insights using Machine Learning.

What it does:
- Classifies reviews into Positive, Negative, Neutral
- Detects priority levels (P0, P1, P2)
- Identifies customer churn risk (competitor mentions)
- Extracts top negative keywords
- Generates a smart action plan for business teams

Tech Stack:
- Python
- Streamlit
- Pandas, NumPy
- NLP (Text Processing)

Input:
Upload a CSV file
