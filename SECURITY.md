# Security Policy

## Supported Versions

This repository is maintained on the current main branch.

## Reporting a Vulnerability

If you find a security issue, avoid opening a public issue with secrets or exploit details.
Report it through the repository owner’s private channel and include:

- what you found
- where it occurs
- how to reproduce it
- the expected impact

## Local Safety Notes

- Do not commit API keys, credentials, model secrets, or personal data.
- Keep generated checkpoints and datasets out of source control unless they are intentionally part of the project.
